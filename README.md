# Trivia for Nano Day 2026!

Nano Day is held October 9th (10/9) annually! (Get it? 10^(-9)=nano)

I created this trivia game based on that, for the kids at the science museum to learn more about nano on Nano Day!

Still making adjustments, but this is what I have so far.

## Serving locally
1. Install requirements ```pip install -r requirements.txt```
2. Run streamlit app ```streamlit run Questions.py```
3. Go to URI from the output in your browser
